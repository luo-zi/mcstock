# MC 股市（mcstock）安装与上手

一个把「回收 — 炒股 — 采购」串起来的 Minecraft 模组：把背包里的东西回收成金币，
在高杠杆行情里做多做空，赚到的钱再买回物资。

---

## 1. 需要什么

| 项 | 要求 |
|---|---|
| Minecraft | **1.21.1**（仅此一版：模组元数据里的版本区间就是 `[1.21.1]`） |
| NeoForge | **21.1.234 或更高**（依赖声明 `[21.1.234,)`；开发与验收用的就是 21.1.234） |
| Java | 21（NeoForge 21.1.x 自带要求） |
| 其它模组 | **无**（纯 NeoForge + 原版，没有前置） |
| 装在哪一侧 | **客户端与服务端都要装**（界面在客户端，行情与账户结算在服务端，`side="BOTH"`） |

## 2. 安装

1. 给 1.21.1 装好 NeoForge 21.1.234（官方 installer，客户端/服务端各一份）。
2. 把 `mcstock-0.1.0.jar` 放进 `mods/` 目录：
   - 客户端：`.minecraft/mods/`
   - 服务端：服务器根目录下的 `mods/`
3. 启动游戏 / 服务器，模组列表里应看到 **MC 股市**（英文名 MC Stock Market，版本 0.1.0）。
4. 卸载：删掉那个 jar 即可。⚠️ 存档里的行情与账户数据**不会**跟着删
   （行情在主世界的 `mcstock_market` 存档数据里，现金与持仓在玩家数据里），
   想彻底清账要连存档一起处理。

单人存档想用第 5 节的调试命令，需要在创建世界时允许作弊（或对局域网开放时开启）。

## 3. 进游戏怎么开始

1. **做出「交易所终端」**（工作台 3×3，材料全是原版物品）：

   ```text
   铁锭  红石  铁锭
   红石  书    红石
   铁锭  红石  铁锭
   ```

   或者直接 `/give @s mcstock:stock_terminal`。

2. **拿在手上右键**打开股市界面（主手 / 副手都行）。界面**不会暂停世界**，行情照跑；
   手上没拿着终端时，离打开位置超过 8 格或换维度会自动关闭（手里拿着终端就没这个限制）。
3. **首次进服自动送 1000 金币**（只送一次，输光了不会再给）—— 没有它购买页只会弹「余额不够」。
4. **三个页面**（标题栏下面的页签切换）：

   | 页面 | 干什么 |
   |---|---|
   | **回收** | shift 点击背包里的物品送进上方 18 格回收栏 → 点「回收」一次性卖掉。**只卖回收栏里的那 18 格**（2026-10-06 起不再连带背包里的同种物品），明细里会列出每种的**单价与小计**，不值钱的东西不会被吞掉、留在栏里。⚠️ **用过的**工具 / 武器 / 护甲不能回收（**全新的可以**，它本身就等于一堆材料）；交易所终端也不能回收。⚠️ 与「负债自动还债」**口径不同**：负债时**任何有耐久的装备都不会被自动变卖**（含全新），因为那是系统未经同意替你卖东西 |
   | **行情** | 左列选企业（钻石矿业 / 红石科技 / 下界贸易）→ 中间看阴阳柱走势 → 右列填**数量**与**杠杆** → 点 **买入**（做多）或 **卖出**（做空）。图下方是**持仓表格**，每行一个仓位，行尾的「平」只平那一仓 |
   | **购买** | 分类 / 搜索 / 翻页浏览全部可买物品 → **左键买 1 个、Shift + 左键买 1 组**，买到的东西直接进背包 |

5. **帮助面板**：标题栏右端、关闭按钮左边的 **?** 按钮。里面分 14 节讲清玩法与确切数值；
   滚轮 / ↑↓ 翻页，ESC 或再点一次 ? 关掉。帮助打开时其它控件全部隐藏，不会点到背后的东西。

## 4. 关键数值一览

| 项 | 数值 |
|---|---|
| **跳价节奏** | **2 秒一跳**（40 tick），标题栏右上角有倒计时 |
| **一根阴阳柱** | 5 跳 = **10 秒** |
| **涨跌配色** | **红涨绿跌**（A 股习惯，和欧美相反） |
| **手续费** | 仓位价值 × **0.20%**，开仓、平仓**各收一次**（往返 **0.40%**） |
| **保证金** | **仓位价值 ÷ 杠杆**（开仓时锁定，之后不随价格变化） |
| **爆仓** | 浮亏吃掉保证金的 **45%** 就强平（爆仓距离 = 45% ÷ 杠杆）；按跳价后的**真实价格**结算 —— 能亏穿保证金，**现金允许为负（欠债）、没有上限** |
| **回收价** | = 物品**估价**（= `max(配方推导, 数据包地板)`）—— **劳动这条路没被削弱** |
| **购买价** | = 估价 × **1.18**（向上取整）→ 买了再卖**必亏** 18% |
| **均值回归** | 每跳把价格往基准价拉 **2%**（价格更黏在基准价附近，追涨杀跌更容易失败） |
| **行情事件** | 每只股票每跳 **0.25%**（≈ 13 分钟一次，动荡期翻倍）；幅度 3~8σ（利空整体 ×1.15）、半衰期 20~60 跳 |
| **盘中异动（插针）** | 每只股票每跳 **0.03%**（≈ 37 分钟一次）：单跳 **−8%~−15%**，之后 3~5 跳**只回补 60%~80%** —— 专打高杠杆 |

一句话口径：**投机（频繁买卖 / 追消息 / 上高杠杆）不容易赚，劳动（挖矿回收）才是可靠路径。**

### 4.1 物品估值分档（回收价 = 这张表当地板，采购价 = ×1.18）

价格锚定「**获取难度 / 稀有度**」，档与档之间保留数量级落差 —— 否则常见资源能直接换稀有资源
（历史漏洞：木头 4 / 钻石 40，玩家数出「50 个木头 = 4 颗钻石」）。
完整地板表见 `data/mcstock/mcstock/item_values/core.json`（里面带每档的锚点理由）。

> ⚠️ 表里的数字是**地板**，不是钉死价：`估价 = max(配方推导, 地板)`。
> 能被合成出来的东西按真实配方一路推到原材料，推出来更高就听推导的 ——
> 所以下面这张表是「**下限**」，实际估价可能更高（尤其是深加工链的末端）。

| 档 | 估价（金币） | 怎么定的 | 代表物品 |
|---|---|---|---|
| 随手可得 | 1 | 徒手 / 最基础工具就能无限刷，挖一片就是一组 | 泥土类、沙子类、石头类、圆石、沙砾、黏土球、树叶 |
| 常见劳动产出 | 1~4 | 要工具或时间，但一条命能刷一堆：砍树、种地、剪羊毛、打小怪 | 原木 4、木板 1、煤炭 2、羊毛 4、作物 2、皮革 3 |
| 常见矿物 / 可再生 | 5~30 | ① 要铁镐 + 地下探索的常见矿物；② **一切可无限刷的东西**（水+岩浆、村民交易、刷怪塔、农场）—— 上限 30 | 铜 6、铁 10、金 16、红石 / 青金石 / 石英 6、紫水晶 8、**黑曜石 20、绿宝石 20、海绵 25、鳞甲 25、鹦鹉螺壳 25、兔脚 20、幻影膜 25** |
| 稀有 | 150~800 | 要长距离探索 / 打结构 / 打 BOSS，一次收益几个到几十个；**这一档不许出现「便宜设施就能刷」的东西** | 钻石 300、下界合金碎片 450、末影珍珠 200、烈焰棒 150、恶魂之泪 250、潜影壳 400 |
| 极稀有 | 800~3000 | BOSS 级 / 结构限定掉落，一次 1~2 个 | 回响碎片 1200、海洋之心 1500、凋灵骷髅头 900、三叉戟 1800、不死图腾 1500 |
| 传奇 | 3000~10000 | 一个存档只有个位数，或要打完最终 BOSS 才拿得到 | 鞘翅 3000、下界之星 3200、附魔金苹果 4000、龙蛋 5000 |

**「换 1 个 X 需要挖多少块泥土」**（泥土 = 1 金币、采购价 = 估价 × 1.18）——
这张表就是稀有度最直观的刻度：

| 物品 | 需要多少泥土 | 物品 | 需要多少泥土 |
|---|---|---|---|
| 圆石 / 泥土 | 2 | 钻石 | **354** |
| 原木 | 5 | 绿宝石 / 黑曜石 / 哭泣的黑曜石 | 24 |
| 煤炭 | 3 | 海绵 / 鳞甲 / 鹦鹉螺壳 | 30 |
| 铁锭 | 12 | 潜影壳 | 472 |
| 金锭 | 19 | 下界合金碎片 | **531** |
| 烈焰棒 / 末影珍珠 | 177 / 236 | 鞘翅 / 下界之星 | **3540 / 3776** |

挖矿回收的量级（一组 = 64 个）：**圆石 64 金币 · 原木 256 · 煤炭 128 · 粗铁 640 · 钻石 300/颗**。
**农作物与相关产物（2026-10-21 补齐）**：种子统一 **1 金币**，作物 **1~4**，产物按配方推导：

| 物品 | 金币 | 说明 |
|---|---:|---|
| 小麦 / 胡萝卜 / 马铃薯 / 甜菜根 | 2 | 常规作物 |
| 小麦种子 / 甜菜种子 / 西瓜种子 / 南瓜种子 | 1 | 可以买来种，也可以把多余的卖掉 |
| 西瓜片 / 甜菜根以外的瓜菜 | 1 | 1 个西瓜 = 9 片 |
| 南瓜 | **4** | 因为「1 南瓜 → 4 南瓜种子」——种子有价，南瓜就必须 ≥ 4，否则拆种子白赚 |
| 可可豆 / 地狱疣 | 3 | 需要特定环境（丛林原木 / 灵魂沙） |
| 甘蔗 / 竹子 / 甜浆果 / 发光浆果 / 海带 / 海泡菜 | 1~2 | 农场产物 |
| 红蘑菇 / 棕蘑菇 | 2 | 暗室农场 |
| 紫颂果 | 4 | 末地作物 |
| 蜂蜜瓶 / 蜂巢 | 5 / 3 | 蜂箱采集 |
| 牛奶桶 | **30** | 等于一个空桶（3 铁锭 = 30），奶是白送的副产品 |
| 西瓜 / 干海带 / 蜂蜜块 / 蘑菇煲 / 蛋糕… | 推导 | 由配方算出来（西瓜 9、干海带 1、蜂蜜块 20、蘑菇煲 4、蛋糕 99） |

这些条目全部在「可再生 ≤ 30」规则内；「买原料 → 做产物 → 回收」逐条验算过**不会白赚**
（见 `ExchangeRateTest#seededRecipesCannotBeArbitraged` 里的 20 条配方）。

**通用规则：凡是可以无限刷的东西（水+岩浆刷黑曜石、村民交易换绿宝石、刷怪塔、骨粉/农场、
溺尸掉落…）一律按材料价定价，不得超过 30 金币、不许进「稀有」档** —— 否则基建就是印钞机
（黑曜石曾经 150、绿宝石曾经 200，都是被这条规则压下来的）。但**门槛高的东西不受这条约束**：
要塞刷怪笼、末地城、远古城市、林地府邸、BOSS 掉落（烈焰棒、末影珍珠、潜影壳、凋灵骷髅头、
三叉戟、不死图腾、鞘翅、下界之星…）按获取门槛定价，必须留在高档。

这张表由单测 `ExchangeRateTest` 守着（进 CI，共 6 条）：钻石 ≥ 300、下界合金碎片 ≥ 500、
鞘翅与下界之星 ≥ 3000；可再生物品 ≤ 30、结构/BOSS 限定物品 ≥ 150；常见资源 ≤ 4 倍价差；
档位不许重叠；「原料与产物都有种子」的配方不许套利。

### 4.2 整合包地板（ATM10 **已内置**，其他整合包照这个写）

大型整合包里有一批**关键资源推不出价**（Allthemodium 的原矿只能挖，没有原版配方），
推导给它们 0，于是「9 个锭做的块」也一起是 0。这类东西靠数据包补一个**地板**。

**ATM10 不用你写**：模组自带 `data/mcstock/mcstock/item_values/atm10.json`，装了 Allthemodium 就自动生效
（没装的存档里标签展开不出来、物品也不存在，条目会被静默忽略，不会刷日志）。

| 键 | 地板 | 说明 |
|---|---:|---|
| `#c:ores/allthemodium` / `#c:raw_materials/allthemodium` / `#c:ingots/allthemodium` | 3000 | ≈ 10 颗钻石、1.6 个下界合金锭 |
| `#c:ores/vibranium` / `#c:raw_materials/vibranium` / `#c:ingots/vibranium` | 15000 | 下界，要 Allthemodium 镐 |
| `#c:ores/unobtainium` / `#c:raw_materials/unobtainium` / `#c:ingots/unobtainium` | 60000 | 其他维度，要 Vibranium 镐 |
| `allthemodium:piglich_heart` | 5000 | BOSS 固定掉 1 个，合金每次要 2 个 |

块、合金、齿轮、装备、压缩块**一条都没写** —— 它们由配方推出来，地板顺着配方往下游传
（9 个锭的块自动是 9 倍）。三档按 ×5 / ×4 拉开，对应 ATM10 的实际获取门槛。

> 定价思路来自 **Upgrader items** 与 **Upgrader: ATM10 Balance**，两者都是 **All Rights Reserved**，
> 所以只能引用方法、不能引用数据 —— 上面这些数字是本项目按 ATM10 的真实配方自行标定的。
> 详见仓库根目录的 [THIRD_PARTY.md](../THIRD_PARTY.md)。

**换别的整合包**：丢一个 `kubejs/data/<你的命名空间>/mcstock/item_values/vip.json`（或直接放进数据包），
同样只写最上游那几种：

```json
{ "values": { "somemod:mythril_ore": 4000, "#c:ingots/mythril": 4000 } }
```

标定流程（**这是唯一正确的调法，别靠猜**）：

1. 进游戏，`/mcstock audit 30` → 看买价最高的 30 件，每行是
   `卖 12000 · 推导 12000（地板 +0）· 买 14160 · 冷却 236分`
2. **「地板 +0」= 这个地板白写了**（推导本来就更高）；**「地板 +3000」= 地板正在托底**，这就是你想要的效果
3. 头部还有三个计数：`有价 / 无价 / 地板冲突`
   - **无价**很多是正常的（没配方又没地板的东西我们不出价、也不收）
   - **地板冲突 > 0 要处理**：那条地板高到「买原料 → 合成 → 卖出」能净赚（已经算进 1.18 的价差）。
     处理方式二选一：把这条地板调低，或者给它的上游材料也补一条地板
4. 日志里还会报「地板指向整合包里不存在的物品」与「标签地板展开不出物品」——
   id / 标签名写错，那些条目不会生效

⚠️ 超后期物品的**时间解锁**封在 **24 小时**以内（`UnlockRules#MAX_REQUIRED_PLAY_SECONDS`）：
一个上千万金币的物品不会显示「再玩 110 天」，而是「再玩 24 小时」——
再久就只能靠「交一整组」证明自己。

还有几条顺手的：

- **杠杆 1 ~ 400**（▲▼ 按 1→2→5→10→20→50→100→200→400 档位跳）；
- **数量 1 ~ 100000 股**（▲▼ 按 ×10 档进；**MAX** = 按当前余额和杠杆能吃下的最大股数）；
- **买卖都是新开仓**：买入开多、卖出开空，**不会互相抵消**；同一只股票可以同时挂多仓和空仓；
- 同时最多 **32 个仓位**，开满要先平掉几个；
- 净值 = 现金 + Σ(各仓保证金 + 各仓浮盈)，标题栏一直显示「余额 · 净值」。

## 5. 调试命令（可选，需要权限 2 = op）

```text
/mcstock money [set|add <金额>]     查余额与净值；set 直接设、add 加钱（金币，可带两位小数）
                                    **金额可以带负号**（如 `set -100` = 负债 100 金币），方便看负债界面
                                    与验证「空中飞人」成就；这条命令是权限 2（管理员）才有的
/mcstock price [set <股票> <价格>]  三只股票的现价与涨跌；set 直接设价（自动夹进价格上下限）
/mcstock advance                    立刻跳一次价，不用干等 2 秒
/mcstock value [hand|held]          手持物品的估价 / 采购价 / 来源（物品种子？标签种子？配方推导？）
/mcstock audit [n]                  买价最高的前 n 件（卖 / 推导 / 地板抬了多少 / 买 / 冷却）
                                    头部报「有价 / 无价 / 地板冲突」三个计数 —— 调地板就靠它
/mcstock positions                  自己的全部仓位（id / 股票 / 多空 / 股数 / 均价 / 保证金 / 浮盈）
```

股票 id 写 `diamond_mine` / `redstone_tech` / `nether_trade`（也认 `mcstock:` 前缀）。

## 6. 常见问题

- **购买页点了没反应？** 第一页是最便宜的物品（按价格升序），点贵的东西会提示「余额不够」。
  先去回收页卖点垃圾，或用 `/mcstock money add 100`。
- **行情是不是停了？** 界面刻意不暂停世界，跳价由服务端驱动；如果倒计时完全不动，
  检查服务端是否卡顿，或（单人）是否装了会暂停世界的模组。
- **中文 / 英文**：界面文案两份语言都有（`zh_cn` / `en_us`），跟随客户端语言。
- **数值想改？** 全部可调数值集中在 `market/StockDefs.java`（跳价节奏、波动率、手续费率、
  爆仓线、杠杆与数量上下限），改完重新构建即可。
