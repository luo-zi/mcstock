# MC 股市

在 Minecraft 里炒股。

挖到的东西能拿去回收换金币，然后在一个每两秒跳一次价的行情里做多或者做空，赚到的钱再买回物资。三只股票、三个页面、一个物品，没有前置模组。

适配 Minecraft 1.21.1 + NeoForge 21.1.234（更新的 21.1.x 也行）。客户端和服务端都要装。

## 先做终端，再右键

交易所终端不难做，四块铁、四份红石加一本书：

```
铁锭   红石   铁锭
红石   书     红石
铁锭   红石   铁锭
```

不想挖矿的话 `/give @s mcstock:stock_terminal` 也一样。拿着它右键就行——对着空气、地面、箱子都能开，不会被箱子抢走这一下。第一次进游戏会送你 1000 金币，够在稳健那只股票上开一手试试水。

界面打开之后建议先点右上角那个问号。规则和所有具体数值都写在那儿，主界面就不用塞一堆说明了。

## 三个页面在做什么

**回收**：把背包里的东西 shift 进上面那 18 个格子，点回收换钱。这里只卖你放进格子的东西，背包里的一概不动——早先的版本会顺手把背包里同类的也卖掉，后来发现太容易误伤，改成现在这样。右边的列表会写清每样东西的单价、这一行的小计，下面合计有几件、一共多少钱。

**行情**：左边三家公司，中间是走势图，右边填数量和杠杆、点买入卖出。图下面那条是可以滚动的持仓表格，一个仓一行，行尾带一个"平"字按钮，点谁平谁。

**购买**：把赚到的钱换回物资。左键买一个，Shift + 左键买一组，东西直接进背包。注意买价是估价的 1.18 倍，买回来再卖出去必然亏，这不是 bug，是故意的。

## 行情是怎么动的

每两秒跳一次价。走势图上的一根柱子是五跳，也就是十秒。价格平时会被往基准价那边拽（每跳 2%），再叠上随机波动和突发事件。单跳不会超过 ±25%，价格也一直待在基准价的 2% 到 500% 之间——能跌得很惨，但不会归零。

三只股票脾气不一样，钻石矿业每跳波动 0.6%，红石科技 1.2%，下界贸易 2.5%。同一个消息砸下来，下界贸易的柱子会比钻石矿业粗好几倍。

另外市场本身有个大环境，会在平静、温和、起伏、动荡之间来回换，一次持续几分钟。动荡的时候波动翻倍，高杠杆的人一般就是在这时候出局的。

## 会出什么事

每只股票有六个有名字的事件，比如矿区塌方、一项红石专利获批、传送门前排起了长队。

事件不是跳一下就完。它带幅度、带半衰期，还会把波动放大——先猛动一下，再用一两分钟慢慢消化掉。行业和宏观上的事会外溢到别的股票，方向有时候是反的：传送门堵了，做贸易的难受，但资金会往稳健的公司跑。标着"坊间传闻"的消息未必是真的，过一会儿可能被澄清，价格先涨后跌。消息还会扎堆，一段时间里同类的新闻连着出。

还有一种很少见的盘中异动：某一跳直接跌 8% 到 15%，之后只回补六到八成。这不是给你抄底的，是专收拾高杠杆的。

## 钱和风险

买入是开多仓，卖出是开空仓，两边互不对冲——你手上可以同时有一张看涨的仓和一张看跌的仓，各算各的账。

数量能填 1 到 100000（十六档和一个 MAX 按钮），杠杆 1 到 400（十八档，低倍那段更密一点）。保证金是仓位价值除以杠杆，手续费按仓位价值收 0.2%，开仓平仓各收一次。爆仓线是保证金亏掉 45%，按跳价之后的真实价格结算——急跌那一跳可能直接穿过爆仓线，把保证金甚至更多现金一次打光。

亏穿是允许的，也就是可以负债。欠着钱的时候，你每秒会自动卖掉背包里能回收、并且没有耐久的物品来还债。工具、武器、护甲和终端本身不会被卖，这条是硬规矩。资金栏第一行的"扛风险"会实时告诉你当前杠杆能扛多少反向波动：×1 是 40%，拉到 ×400 只剩 0.11%。

## 东西值多少钱

物品的价按稀有度和获取难度分六档，从顺手就能挖的（泥土、圆石，一块一金币）到一个存档也没几个的（鞘翅 3000、下界之星 3200、龙蛋 5000）。

能无限刷的东西一律按材料价算：黑曜石、绿宝石、海绵这些都压在 30 金币以内，不管它在原版里多金贵。真正值钱的只有不可再生的：钻石 300、下界合金碎片 450、潜影壳 400。

有个好用的尺子：一颗钻石差不多等于 375 块泥土。五十根木头是买不起的。

## 为什么我把它做成赌不赢的

炒股游戏很容易变成"点点点就发财"，我不想做成那样，所以有三处是特意设计的。

界面不会告诉你该买还是该卖。新闻只说发生了什么——"矿区发生塌方"，不写涨跌百分比，不标牛市熊市，也不染红绿；大环境只用"平静、温和、起伏、动荡"这种不带方向的词。想知道涨跌，自己看走势图。

投机长期是亏的。往返手续费 0.4%，买卖价差 18%，而单跳的波动比这两个数大一个量级。我拿模拟跑过五十五个小时的游戏时间：追消息、死多 ×400、来回倒腾这三条路，本金都亏掉八成以上，光手续费就吃掉 1.5 倍本金；唯一稳定为正的是老老实实回收不交易。

说白了，它模拟的是行情，不是教人炒股。你可以低杠杆稳稳玩，也可以去赌，但赌之前，代价已经写在杠杆框旁边了。

## 安装和命令

装好 NeoForge 之后把 jar 丢进 `mods/`，客户端服务端都要。进游戏做出终端或者 `/give` 一个，右键开界面。

调试命令（权限 2）：

```
/mcstock money              看余额和净值
/mcstock money add 100      加 100 金币
/mcstock money set -50      把余额调成 -50，试试负债
/mcstock price              三只股票的现价和涨跌
/mcstock price set diamond_mine 100
/mcstock advance            立刻跳一次价
/mcstock value              看手持物品的估价和来源（种子价、标签价还是配方推出来的）
/mcstock positions          列出自己的仓位
```

## 给做整合包的人

物品估价是数据驱动的，改 `data/mcstock/mcstock/item_values/core.json` 然后 `/reload` 就行。能合成的物品一律由配方推出来，推导过程守着一条不许套利的约束——任何配方都不能变成印钞机。经济常量（跳价节奏、手续费、杠杆上下限、爆仓线、事件幅度）都是源码里的普通常量，旁边写着为什么是这个数。

代码里有 124 个单测，比较特别的两个：一个是经济模拟（三条投机策略必须亏、只回收必须赚），一个是估值不变量（配方不许套利）。布局也有一套矩阵自检，九种分辨率逐块检查有没有重叠。
