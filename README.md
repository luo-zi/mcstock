# MC 股市（mcstock）

> 一个装进 Minecraft 的股市小游戏。**把背包里的东西回收成金币，在 2 秒一跳的行情里做多/做空，再用赚到的钱换回物资。**

- **两个平台版本**：Minecraft **1.21.1（NeoForge）** 与 **1.20.1（Forge / NeoForge 通用）**
- **无前置模组**，无第三方依赖
- 模组 ID：`mcstock` · 主包 `com.qiushaonan.mcstock`

## 玩法

### 三个页面

| 页面 | 做什么 |
|---|---|
| **回收** | 把你挖到/打到的物品 shift 进 18 格回收栏，点「回收」换金币。明细写清每样东西的**单价与小计**、合计的**件数与总价**；只卖栏里的，背包不动 |
| **行情** | 三只股票的阴阳柱走势图 + 数量/杠杆填写栏 + 买入（开多）/ 卖出（开空）；图下方是**可滚动的持仓表格**，每行行尾一个「平」按钮单独平仓 |
| **购买** | 用金币把物资买回来（单价 = 估价 × 1.18）。左键买 1 个、Shift + 左键买 1 组，物品直接进背包 |

标题栏右上角的「**?**」是帮助面板：规则与全部数值都在里面，主界面保持干净。

### 行情怎么动

- **每 2 秒跳一次价**；一根阴阳柱 = 5 跳 = **10 秒**
- 价格 = 均值回归（2%/跳）+ 随机波动 + 行情事件；单跳不超 **±25%**，价格被夹在基准价的 2%~500%
- 三只股票波动不同：**钻石矿业 0.6% / 红石科技 1.2% / 下界贸易 2.5%**（每跳 σ）
- **市场环境**在「平静 / 温和 / 起伏 / 动荡」之间切换（几分钟一次），影响波动与偏向
- 每只股票有 **6 个具名事件**（矿区塌方、红石专利获批、传送门排长队…）：带**幅度 / 半衰期 / 波动放大**，行业与宏观事件会**外溢**到其它股票，标着「坊间传闻」的之后可能被**澄清**（先涨后跌），消息还会**扎堆**
- 罕见的「**盘中异动**」：单跳急跌 8~15%，之后只回补六到八成 —— 专打高杠杆

### 交易与风险

| 项 | 数值 |
|---|---|
| 方向 | **买入 = 开多**，**卖出 = 开空**；两者**互不对冲**，各自独立成仓（最多 32 个） |
| 数量 / 杠杆 | 1 ~ 100,000（16 档 + MAX） / 1 ~ 400（18 档） |
| 保证金 | 仓位价值 ÷ 杠杆 |
| 手续费 | 仓位价值 × **0.20%**（开、平各一次，往返 0.40%） |
| 爆仓线 | 保证金亏 **45%** 即强平（按跳价后的真实价格结算） |
| 负债 | **允许欠钱**。欠债时每秒自动变卖背包里**可回收且无耐久**的物品还债 —— 工具 / 武器 / 护甲 / 终端**不会被卖** |

### 成就「空中飞人」

**欠着钱**从 **≥100 格**高处**摔死**（死因必须是摔落伤害）→ 获得成就「空中飞人」，并且**债务一笔勾销**（余额置 0）。
边界：刚好 100.0 格算达标；余额 0 或正数不触发；被水接住 / 不死图腾救下来不触发。

### 物品怎么定价

按**稀有度与获取难度**分 6 档，从「随手可得」（泥土、圆石：1 金币）到「传奇」（鞘翅 3000、下界之星 3200、龙蛋 5000）。
**可再生资源一律按材料价**（黑曜石、绿宝石、海绵 ≤30 金币），不可再生的才值钱：钻石 300、下界合金碎片 450、潜影壳 400。

> 一把好用的尺子：**一颗钻石 ≈ 375 块泥土**（50 根木头换不到）。

## 设计取向：它**不**教你炒股

三件事是刻意做的：

1. **界面不替你下判断** —— 新闻只叙述发生了什么（「矿区发生塌方」），**不写涨跌百分比、不标牛熊、不按红绿染色**；市场环境只用「平静/温和/起伏/动荡」这类不含方向的词。要看涨跌，自己读走势图。
2. **投机长期是负期望** —— 往返手续费 0.40% + 买卖价差 18%，而单跳波动比这两个数大一个量级。仓库里的 `EconomySimulationTest` 用 10 万跳模拟过：**追事件 / 死多 ×400 / 频繁往返三条路，本金都亏掉八成以上**（光手续费就吃掉 1.5 倍本金）。
3. **劳动是稳的** —— 只回收不交易那条对照路线稳定为正。

> 换句话说：它模拟的是行情，不是「投资建议」。你可以低杠杆稳稳玩，也可以去赌 —— 代价已经写在杠杆框旁边。

## 安装

1. 装好 **Minecraft 1.21.1 + NeoForge 21.1.234+**（1.20.1 用 **Forge 47.2.20+ / NeoForge 47.1.x**）
2. 把 jar 丢进 `mods/`（**客户端与服务端都要装**）
3. 做出**交易所终端**，或 `/give @s mcstock:stock_terminal`：

   ```
   铁锭  红石  铁锭
   红石  书    红石
   铁锭  红石  铁锭
   ```

4. **右键**使用（对着空气、地面、箱子都行）。第一次进游戏送 **1000 金币**。

### 命令（权限 2）

```text
/mcstock money [set|add <金额>]     查余额/净值；金额可带负号（set -100 = 负债 100）
/mcstock price [set <股票> <价格>]  三只股票现价与涨跌
/mcstock advance                    立刻跳一次价
/mcstock value [hand|held]          手持物品的估价与来源（种子 / 标签 / 配方推导）
/mcstock positions                  自己全部仓位
```

## 开发

```powershell
.\gradlew.bat build        # 编译 + 全部单测
.\gradlew.bat runClient    # 开发客户端
```

| 项 | 值 |
|---|---|
| 构建 | Gradle + **NeoForge ModDevGradle** 2.0.141 |
| 映射 | Parchment 2024.11.17 |
| 单测 | **159 个**（纯 JVM，含经济模拟 / 估值防套利 / 布局重叠矩阵 / 网络包极端输入） |

### 代码结构要点

- **布局单一来源**：`client/StockGuiLayout.java` 是纯 Java（不 import Minecraft），文档、效果图、贴图坐标都从它生成，并用 `StockGuiLayoutTest` 在多种分辨率下断言「块不重叠 + 文字不压边框」。
- **服务端权威**：价格、余额、持仓、估值全在服务端算；客户端只发「点了哪个按钮」。
- **可复现行情**：固定种子 + 已跳次数重放；阴阳柱用**绝对分箱**，已完成的柱子永不重算。
- **数值不变量有测试守着**：估值不许套利、单跳 ≤±25%、爆仓距离 = 45%÷杠杆、网络包超限只截断不抛异常。

### 工具脚本（`tools/`）

| 脚本 | 干什么 |
|---|---|
| `gen_gui_textures.py` | 生成 GUI 图集（含坐标自检） |
| `gen_small_font.py` | 生成小号点阵数字字体 |
| `gen_gui_spec.py` / `gen_gui_mockup.py` | 从布局生成规格文档 / 效果图 |
| `layout_dump.py` | 输出任意分辨率的全部控件矩形（改界面前先看它） |
| `check_lang_keys.py` / `check_item_values.py` | 校验中英语言键 / 估值表键是否存在 |
| `economy_sim.py` | 经济蒙特卡洛（直接解析 Java 常量） |
